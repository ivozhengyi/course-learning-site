# 一次完整交付的验收门槛

这些是默认完整学习网站的完成条件。用户明确缩小范围时调整对应项目并记录原因，不能用一张空壳页面冒充“已支持”。每项记录执行方式、范围、实际结果和失败修复；“计划检查”不能写成通过。

## 1. 资料与内容

- 资料原件和提取内容可追溯；有页码来源的概念确实能在相应原页找到。重要试题已经看原图，重复、样卷、笔记、参考解答身份明确。
- 从实际内容生成覆盖矩阵与题量，不维护一份与网站无关的手填统计。每个核心知识点都有初学讲解、复习落点和两轮对应题；每节初学都有课堂小练。审计脚本检查覆盖，人工通读检查是否真能理解。
- 全部初学小节通过先修、术语、例子、因果与图文一致性通读。复习不堆重复概念，核心记忆点可追溯、可自测；重要细节全覆盖，冷门补充分开。
- 两套内容的任务、详略和题目实际不同。不能复用同一道题只改 ID；独立模式允许讨论同一原理，但应换情境、步骤或认知任务。
- 各章题量、题族和层次与证据相符；易题与难题都有，重要章节训练更充分。所有计算题复算，概念题及其所有选项逐道审读。对照原题要求，确认未漏中间任务。

## 2. 公式、图和过程演示

- 全量遍历作者编写的公式字符串，用渲染器检查语法；浏览器查看求和上下限、分式、上下标、积分、复数、矩阵、取整、单位及长公式。不能用 ASCII `x^2` 代替主内容数学排版。
- KaTeX/MathJax 与字体本地完整，离线仍正常。代码不被数学识别改写；选项标签、IP 地址、比特串、路径和斜杠不被错排成分式。输入框与原始文献可保留文本。
- 图中数值、方向、颜色和正文一致。使用 SVG、HTML、Canvas 等适宜方式画课程图，不把生成的装饰图当准确的电路/协议/波形示意。
- 演示有明确输入、当前步骤、发生什么和为什么，支持预设例子、播放/暂停/单步/重置；必要时调速。开始、结束和重播不越界，不重复授予经验。不能只动颜色而没有知识解释。

## 3. 判分与组卷

- 自动题实际提交正确、错误、空白、边界输入；核验单位、分数、小数、负数、序列分隔、空槽以及允许的等价答案。不给任意符号代数能力做虚假承诺。数值误差按量纲和题目精度设置，不能统一照搬某门课容差。
- 分项题部分正确按规则给部分分，漏填不移位。主观题明确自评，待自评时总分标为不完整；参考答案不声称官方。
- 对多解题实际提交另一组合法答案，同时提交一组看似合理但不合法的答案；合法性与最优性均要核对。
- 各章节、层次、题型、专题、未练、错题组合筛选，预览数量和实际题数一致。题族去重，核心覆盖率排除可选补充。初学默认抽题不涉及未来先修。
- 有模拟考时：覆盖卷面需要的题型和完整任务；没有卷面证据就标明训练编排。答题前没有答案/暗示；支持跳题、返回修改、暂存、刷新续答；交卷包含当前草稿，空题零分。自评未完成时可稍后恢复，自动分/自评分分列。
- 用已核对答案走完一整份模拟，再用部分错误与留空检验分数，不能只看组卷成功。

## 4. 学习闭环与记录

- 用户能从两入口明确知道先做什么、答错后回哪里补学、复习优先练什么。课内图解、课堂小练、正式练习的关系直观。
- 首次掌握记录与重复点击区分。XP 表示参与，完成度不伪称真实能力；错题复练后保留必要历史，薄弱项统计有清楚依据。
- 收藏、笔记、搜索及速查均包含新增内容，搜索结果能到正确模式/专题。返回保留合理位置，长页不需要用户来回找按钮。
- 刷新后进度、草稿、笔记、待自评恢复；两模式互不串档。导出后导入恢复相同内容；处理错误/旧版本文件有可读反馈。迁移保留原 ID，避免清空旧记录。
- 在独立浏览器来源或隔离测试存储中验收，不能清理用户真实地址的存档。离线文件的存储限制如实说明并提供 JSON 备份；不能声称跨设备自动同步。

## 5. 真浏览器与布局

先检查环境可用的浏览器工具并遵守其操作规则，再实际访问和点击；静态读取 HTML 或伪造 DOM 不能算视觉验收。

- 默认至少桌面约 1440×900、平板竖屏约 768×1024；用户指定设备优先。全部知识页布局可批量遍历，代表性题型和全部交互类别实际操作。
- 无全页横向溢出、文字遮挡、按钮被固定栏盖住、公式截断。长表只在局部滚动；图的标签清晰，平板可操作。
- 导航抽屉有遮罩与关闭操作，键盘焦点可见，输入有标签，折叠按钮状态正确。颜色不是唯一正误提示。
- 查看控制台和资源加载失败；断网后入口、公式、题库、演示和资料仍可使用。测试结束关闭自己创建的预览资源，不动用户无关标签。

若浏览器能力不可用，先交付可运行文件和已完成的其他核验，明确“浏览器验收未完成”，不能编造截图或称已达到全部门槛。

## 6. 交付与维护

网站文件夹至少包括：入口、内容和资源、学习记录备份入口、使用说明、资料/考法与分层题量说明、维护来源/构建方式、可复跑检查和验收记录。原件能否随目录分发按用户范围决定；不要复制与课程无关的私人文件。

验收记录标出版本、时间、覆盖范围、实际通过/失败与遗留限制，附代表性知识页、练习页和小屏截图。统计从内容生成，修改后更新，历史报告标为历史，避免相互矛盾。

不要求所有项目用同一种框架。默认离线 HTML 可用本地静态数据避免 `file://` 下 fetch/module 限制；如需服务端或联网能力必须在项目约定中说明。不得以插件要求为由擅自部署或上传资料。

预算/时限：先安排资料、核心内容、题库、验收和交付余量，过程中按风险调整；剩余时间优先用于未验证的重要题族和学习障碍。不能靠重复无意义检查或扩充冷门题耗尽额度。若约束不可兼得，及时说明实际缺口，不默默缩减承诺范围后宣布完整。
