# 跨课程适配：迁移教学方法，不迁移数据结构题型

以下是内容审查提示，不是课程大纲或命题预测。以用户提供的资料和已确认版本为准；具体标准、协议行为和有疑问的公式查证权威原始来源。未出现在范围内的主题不自动加入主线。

## 计算机网络

适宜的理解单位是“一个数据如何经过一层/一段链路，以及状态为什么改变”。初学可用小网络图、逐层封装、报文时间线、路由表一步更新；复习则对应字段含义、成立条件、时序推算和综合计算。

| 主题 | 适合的小例子/演示 | 出题前必须说明或核对 |
| --- | --- | --- |
| 时延与吞吐 | 一段链路再到两段链路，展示发送和传播的区别 | bit/Byte、十进制/二进制容量、报文/分组长度、首比特/末比特到达、处理/排队时延是否计入、存储转发或其他模型 |
| 子网与地址 | 一个小地址块分配给少量子网 | IPv4/IPv6、前缀长度、网络/广播/可用地址的适用规则；特殊前缀按明确模型，不机械套“总数减二” |
| 可靠传输 | 预设丢包、超时和重传的一次过程 | 序号按字节还是分组、ACK 含义、接收缓存、累计/选择确认、窗口和环绕规则 |
| TCP | 数据段和 ACK 的时序图、状态迁移 | 哪些简化假设、连接阶段、实现/教材版本；拥塞窗口单位、阈值、超时/重复 ACK 情形及取整不能省略 |
| 路由 | 小拓扑的距离/下一跳逐轮更新 | 邻居顺序、初始表、链路方向、代价、轮次同步方式；等价路由可能多解 |
| 链路与检错 | 一帧发送或一组小多项式除法 | 位序、生成多项式写法、补零与余数宽度，不能省略前导零；协议限定范围 |

避免把协议层的抽象功能和某个现实设备/产品实现混为一谈。概念题干扰项应来自封装层次、转发依据、广播域、可靠性条件等实际误解，不靠无关名词陪衬。

独立复核可用小规模离散事件追踪、逐比特除法、地址区间枚举、路径枚举和量纲检查；仿真只证明明确模型，不自动代表真实网络的全部行为。

## 通信原理

先补理解当前例子所需的数学先修，例如相位、复数、积分、概率或频谱。不要一开场堆完整推导。把“看到什么波形→操作改变了什么→为什么→一般公式”连起来；复习同时训练概念、适用前提、公式选择和计算。

| 主题 | 适合的小例子/演示 | 出题前必须说明或核对 |
| --- | --- | --- |
| 时频与频谱 | 一个简单基带信号及调制前后频谱 | Hz/rad·s⁻¹、变换归一化、单/双边频谱、实/复信号、幅度与功率的区别 |
| 调制解调 | 预设码元对应的幅度、频率或相位变化 | 载波幅度/功率定义、相干条件、映射关系、带宽口径；不能用单一图适配所有调制方式 |
| 采样与量化 | 稀疏采样点、重建与量化阶梯 | 带限假设、采样条件和等号边界、混叠、位数与电平数、过载/均匀量化假设 |
| 码元与比特 | 少量比特映射成 M 进制码元 | 码元率/比特率、每符号比特数、净荷/编码开销；M 与映射前提明确 |
| 噪声与性能 | 同一信号加噪后比较判决 | SNR、Eb/N0、Es/N0、线性与 dB 的转换；噪声谱密度单/双边、Q 函数或 erfc 关系按教材约定 |
| 滤波与判决 | 一组脉冲经过滤波后在时刻取样 | 卷积/相关符号、时间反转、采样时刻、归一化、ISI 条件与理想假设 |
| 编码与概率 | 一小组源符号或码字 | 概率是否归一、熵单位、码长与编码效率定义、距离和纠检错能力适用条件 |

题干里的波形不能只是图片装饰：标出时间、幅度、周期/码元边界和需要读取的位置。纯颜色区分在灰度下仍需标签。小屏坐标和公式可读。

独立核验可用符号推导与数值积分交叉检查、功率/概率归一、极限情形和量纲检查。数值仿真必须标明随机种子、样本数和近似误差；不能用少量随机结果证明精确误码率公式。

## 其他课程

先确定课程的核心表示（状态、空间结构、时间线、信号、证明或系统模型），再选图与交互。算法动画只是其中一种形式；电路、数学、操作系统、数据库等课程各用真实的任务与边界。不在没有考卷时把通用题型称为“本校历年必考”。
